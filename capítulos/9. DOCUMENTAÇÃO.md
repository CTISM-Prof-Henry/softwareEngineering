# Documentação

A documentação de um software é um conjunto de informações que descrevem o funcionamento, a utilização e a manutenção do
software. Ela é essencial para garantir que os usuários e desenvolvedores possam compreender e utilizar o software de
forma eficaz.

Quando falamos de documentação, falamos geralmente de dois tipos: ou um manual, em texto livre, que explica como o
software funciona, ou uma documentação de API, que descreve as funções e métodos disponíveis para interação com o
software. A documentação de API é especialmente importante para desenvolvedores que desejam integrar o software com
outros sistemas ou criar extensões e plugins.
